# Arrow Wheel

Draws an arrow on the map.

## Draw an arrow

1. Hold `` ` `` (the draw key).
2. Press and hold `Q`. The arrow starts at the cursor.
3. Move the mouse to aim.
4. Release `Q`. The arrow is drawn.

## Cancel

- Press `Esc`.
- Or release `Q` near the start point.

## Change the key

1. Open **Keybinds**.
2. Search for `arrow_wheel`.
3. Set a new key.

## Notes

- While `` ` `` is held, the mouse buttons draw on the map as usual.
- Long arrows take a moment to appear. BAR limits how fast map lines are sent.
- If the KeySelect widget is on, `` ` `` + `Q` selects units instead. Change the key.
