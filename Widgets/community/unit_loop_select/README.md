# Loop Select

**Description:** Hold a key and drag to draw a freehand loop around the units you want selected, instead of a box.

- **Author:** Niobium
- **License:** GNU GPL, v2 or later
- **Layer:** 0
- **Enabled by default:** true

## Usage

Hold the loop key (Space by default) and drag with the left mouse button to draw the loop. Release to select what's inside.

- Hold Shift while drawing to add to the current selection.
- Hold Ctrl while drawing to remove units from the current selection.

The keys can be changed in the keybind editor, under Loop Select. Box select filters such as idle or mobile only still apply to the loop.

Used to ship with the game; moved here so players who want it can install it.
